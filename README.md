# Learning Dashboard Platform

A comprehensive learning management system with role-based dashboards for coordinators, educators, and learners.

## Features

- **Multi-role Dashboard**: Separate views for coordinators, educators, and learners
- **Course Management**: Create, edit, and manage courses with rich content
- **Assignment System**: Submit and grade assignments with rubrics
- **Study Plans**: Personalized learning paths
- **Payment Simulation**: Mock payment processing
- **Analytics**: Track progress and performance
- **Discussion Forums**: Interactive learning community

## Tech Stack

### Frontend
- React 18 with TypeScript
- Material-UI v5 for components
- Redux Toolkit for state management
- Recharts for data visualization
- React Hook Form for forms

### Backend
- Node.js with Express
- MongoDB with Mongoose
- JWT authentication
- Cloudinary for file storage
- Nodemailer for emails
